Biswas IT Firm — IT Agency Website

A modern, responsive, and interactive IT agency website built with React.js, React Router, JavaScript, and Tailwind CSS.

The website showcases professional IT services, introduces team members, and provides an interactive user experience through dynamic JSON data loading, category filtering, and team member search functionality.

Technology Used:

React
Tailwindcss
JavaScript
React Router
Fetch API
Async/Await
JSON
